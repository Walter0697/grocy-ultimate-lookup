GitHub PAT

  1. Open GitHub, then click your avatar in the top-right corner.
  2. Go to Settings, then Developer settings.
  3. Open Personal access tokens, then Fine-grained tokens.
  4. Click Generate new token.
  5. Name it something like Grocy catalog push.
  6. Choose an expiration date.
  7. Under Repository access, choose Only select repositories.
  8. Select your catalog repository, for example grocy-testing.
  9. Under Repository permissions, set Contents to Read and write.
  10. Click Generate token, copy it, and paste it into the GitHub PAT field here.
